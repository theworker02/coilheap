# coilheap

Coil CSV/TSV heap tables for quick inspection and cleanup.

**Site:** https://theworker02.github.io/coilheap/

## Install / run

```bash
git clone https://github.com/theworker02/coilheap.git
cd coilheap
node src/cli.js
node --test
```
